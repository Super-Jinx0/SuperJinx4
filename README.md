# Jinx (جینکس)

پنل خصوصی هوش مصنوعی: هر مدل با یک API سازگار با OpenAI، با تم و رنگ اختصاصی هر برند (Claude، Gemini، GPT، Grok، DeepSeek و ...)، نمایش زنده کارِ هوش مصنوعی (فکر کردن، نوشتن، ساخت فایل‌ها)، ساخت سایت با پیش‌نمایش و ZIP، ساخت تصویر با بهبود هوشمند پرامپت، ساخت و دانلود ویدیو، حافظه ماندگار.

## اجرای محلی (Node 22.13 یا بالاتر)

    ADMIN_PASSWORD="یک-رمز-قوی-حداقل-۸-کاراکتر" node index.js

سپس http://localhost:8080 را باز کن.

## تست خودکار

    node test.js

## استقرار روی Railway

1. فایل‌های همین پوشه را روی GitHub بگذار.
2. Railway: New Project، Deploy from GitHub repo.
3. Settings، Volumes، Add Volume، Mount path برابر `/data`.
4. Variables: `ADMIN_PASSWORD` (رمز قوی) و `SECRET_KEY` (رشته تصادفی حداقل ۳۲ کاراکتر).
5. Settings، Networking: پورت ۸۰۸۰، سپس Generate Domain.
6. وارد شو، در «اتصال» آدرس و کلید API را بده و «تست اتصال» را بزن.

بدون Volume، با هر دیپلوی همه داده‌ها پاک می‌شود.

## ساخت تصویر و ویدیو

- تصویر: در «اتصال» یک مدل تصویر (مثلا google/gemini-2.5-flash-image-preview یا openai/gpt-image-1) انتخاب کن. نسبت، سبک و تعداد از نوار بالای کادر پیام تنظیم می‌شود و پرامپت به‌صورت هوشمند حرفه‌ای‌تر می‌شود.
- ویدیو: سرویس باید مسیرهای سازگار با OpenAI (`POST /videos`، `GET /videos/{id}`، `GET /videos/{id}/content`) داشته باشد، مثل sora-2. نام مدل را در «اتصال» بنویس. اگر سرویس تو این مسیرها را ندارد، ساخت ویدیو کار نمی‌کند.
- با روشن بودن «تشخیص خودکار»، نوشتن «یه عکس خفن بساز» یا «یه ویدیو بساز» خودش مدل مناسب را صدا می‌زند.

## متغیرهای محیطی

| نام | توضیح |
|---|---|
| ADMIN_PASSWORD | الزامی. رمز ورود |
| SECRET_KEY | پیشنهادی. کلید رمزنگاری (حداقل ۳۲ کاراکتر) |
| DATA_DIR | مسیر داده‌ها. در Docker برابر /data |
| PORT | پورت. پیش‌فرض ۸۰۸۰ |
| MAX_UPLOAD_MB | سقف حجم آپلود. پیش‌فرض ۲۵ |

## قرارداد فایل‌ها

مدل هر فایل را در یک بلاک کد با `file:مسیر` می‌دهد، مثلا ` ```html file:index.html `. برنامه آن‌ها را به فایل قابل دانلود، ZIP و پیش‌نمایش زنده تبدیل می‌کند.

## قابلیت‌های نسخه ۳ و ۴

- زبان‌ها: فارسی، English، العربية، Türkçe (دکمه کره زمین در سایدبار).
- اعتبار باقی‌مانده API در سایدبار و صفحه مصرف (OpenRouter، DeepSeek و پروکسی‌های سازگار).
- دانلود عکس، ویدیو و صدای ویدیو (MP3, WAV, M4A). نیاز به ffmpeg (در Dockerfile هست).
- ساخت سریع (دکمه ⚡): پروژه جمع‌وجور و فوری.
- بررسی خودکار پروژه: خطای نحوی JS، JSON، CSS، فایل‌های ناموجود و پاسخ نیمه‌کاره. خطاهای زمان اجرا در پیش‌نمایش هم گرفته می‌شود و دکمه «رفع خودکار» دارد.
- اتصال‌های ذخیره‌شده: چند کلید را نگه دار، جابه‌جا شو یا حذف کن (رمزنگاری‌شده، هرگز به مرورگر نمی‌رسد و در خروجی JSON نیست).
- بسته انتقال حافظه: دانلود Markdown/JSON، خلاصه هوشمند برای هوش مصنوعی دیگر، و وارد کردن حافظه.
